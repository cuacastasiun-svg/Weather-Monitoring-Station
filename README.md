# 🌦️ Dashboard 5 Parameter + Icon Branding Edition

Dashboard pemantauan stasiun cuaca yang kini dilengkapi dengan **logo/ikon khusus (Font Awesome)** di setiap judul panel parameternya, memberikan identitas visual yang lebih profesional dan estetik.

## ✨ Pembaruan Fitur
1. **Icon Branding di Panel Header:** 
   - 🌡️ **Temperature:** Ikon termometer bersuhu tinggi.
   - 💧 **Humidity:** Ikon titik air / droplet.
   - 💨 **Wind Speed:** Ikon hembusan angin.
   - ☀️ **Solar / Light:** Ikon sinar matahari / cahaya.
   - 🌧️ **Rainfall:** Ikon awan hujan.
   - 💻 **System Information:** Ikon server sistem.
2. **Desain Tetap Simetris & Bersih:** Tata letak 3 kolom dengan kondisi awal kosong (*default empty*) sebelum dihubungkan ke Firebase Anda.

## 🚀 Instalasi & Penggunaan
- Ekstrak folder, lalu buka file `index.html` menggunakan peramban (browser).
- Masukkan konfigurasi Firebase Anda di bagian bawah script untuk mulai menerima data secara *real-time*.
