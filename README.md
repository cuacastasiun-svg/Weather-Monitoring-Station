# ⚡ Dark Neon Polinela Weather Monitoring Dashboard

Dashboard monitoring cuaca IoT bertema **Dark Neon** dengan logo resmi Polinela yang terpasang di pojok kiri atas *sidebar*, serta judul **Weather Monitoring Station** tepat di bawahnya.

## ✨ Pembaruan Fitur
1. **Logo Polinela di Sidebar:** Logo institusi Polinela ditambahkan di bagian atas kiri dengan efek pendaran cahaya neon.
2. **Judul Resmi:** Menampilkan tulisan **Weather Monitoring Station** di bawah logo.
3. **5 Parameter Utama + Logo Diperbesar:** Memuat 5 parameter (Suhu, Kelembapan, Angin, Cahaya, Curah Hujan) dengan ikon masing-masing parameter yang berukuran besar dan tajam.
4. **Tanpa Tulisan Ekstra:** Keterangan teks `(5 Parameter)` telah dihapus dari judul halaman utama.

## 🚀 Cara Pemasangan
1. Ekstrak folder ZIP ini.
2. Masukkan file gambar logo Polinela Anda ke dalam folder yang sama, lalu beri nama file tersebut `logo_polinela.png` (atau ubah kodenya sesuai nama file Anda).
3. Unggah seluruh isi folder ke repositori GitHub Anda dan aktifkan GitHub Pages.
