# ⚡ Dark Neon 5-Parameter Weather Dashboard

Dashboard monitoring cuaca IoT dengan estetika **Dark Neon** murni (latar belakang hitam pekat, aksen *glowing* biru laut/cyan, dan warna indikator menyala terang).

## ✨ Fitur & Perubahan Terbaru
1. **Pembersihan Total Panel Ekstra:** Bagian *Heat Index* dan *System Information* telah dihilangkan sepenuhnya. Halaman utama kini **hanya berisi tepat 5 kotak parameter utama** (Suhu, Kelembapan, Kecepatan Angin, Cahaya, dan Curah Hujan).
2. **Tema Warna Dark Neon:** Menggunakan kombinasi warna hitam gelap (`#030508`), bingkai panel dengan efek pendar (*glow*) cyan neon, serta ikon bermacam-macam warna terang (Pink untuk Suhu, Biru Cyan untuk Kelembapan, Hijau untuk Angin, Kuning untuk Cahaya, dan Ungu untuk Hujan).
3. **Grafik & Tabel Kosong Default:** Grafik dan tabel riwayat histori akan bersih tanpa data palsu sampai perangkat IoT Anda mengirimkan data nyata dari Firebase.
4. **Export Excel (CSV):** Fitur unduh log data riwayat tetap aktif dan siap digunakan.

## 🚀 Cara Pemasangan di GitHub
1. Ekstrak folder ZIP ini.
2. Unggah file `index.html` ke repositori GitHub Anda.
3. Hubungkan dengan Firebase Realtime Database Anda menggunakan blok kode di bagian bawah `index.html`.
